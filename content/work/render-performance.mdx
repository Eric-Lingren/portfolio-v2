## Key decisions

**Measure before changing anything.** I profiled the site with Lighthouse and used the 10-28-21 run on dev.insideoutdev.com as the baseline. That run scored 47 for performance, with a first contentful paint of 4.0s and a largest contentful paint of 5.2s.

**Fix the largest cost first.** The biggest cost Lighthouse found was images. Its opportunities list for that run put properly sized images at about 6.36s of potential savings, next-gen image formats at about 2.4s, and render-blocking resources at about 0.9s. So images came first: they were resized and compressed before anything else.

**Then change how the code loads.** After the images, I converted standard component imports to lazy imports and moved the mounting of components on each route to React Suspense. I made the third-party scripts load asynchronously and deferred the render-blocking resources that were left. [ERIC: how did you ship these changes? One at a time, behind a flag, or in one release?]

| Speed Index | 6.1s | 1.6s |
| Time to Interactive | 4.3s | 2.1s |
| Total Blocking Time | 190ms | 150ms |

These are two lab runs on the development site, not production traces. Largest contentful paint fell by 3.2s, and Speed Index fell by 4.5s. Total Blocking Time moved the least, from 190ms to 150ms.
